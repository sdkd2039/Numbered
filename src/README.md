# بنية Worker معدودات

## ما تم حتى الآن
- `index.js`: نقطة تجميع التشغيل ومسارات لوحة الإشعارات والأرشيف ومركز الملفات.
- `shared/http.js`: استجابات JSON وHTML والتحقق من الروابط.
- `pwa/handlers.js`: معالجات manifest وService Worker وأيقونة التطبيق.
- `worker.js` في جذر المستودع: مدخل توافق يحوّل إلى `src/index.js`.

## التقسيم المتبقي
- `notifications/`: OneSignal والإشعارات والأرشيف والجدولة.
- `files/`: مركز الملفات والتخزين وعمليات الرفع والحذف.
- `sheets/`: خدمة الجداول باستخدام D1 binding باسم `SHEETS_DB`.
- `shared/`: أدوات HTTP والتحقق المشتركة.

## ملاحظات السلامة
- هذه إعادة هيكلة تدريجية؛ لم تُفصل بعد وحدات الإشعارات والملفات ولم تُفعّل واجهات Sheets.
- يجب الحفاظ على KV binding `NOTIFICATION_ARCHIVE` وX02 وOneSignal كما هي.
- قاعدة D1 الحالية `numbered_sheets_db` مربوطة باسم `SHEETS_DB`، ولا ينبغي حذفها أو إعادة إنشائها.
- لا يتم النشر إلى Cloudflare إلا بعد اختبار البناء والمسارات والإعدادات.
