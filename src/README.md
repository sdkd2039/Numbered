# بنية خدمات معدودات

نقطة تشغيل Cloudflare Worker الحالية هي `src/index.js`، ويظل `worker.js` في جذر المستودع كمدخل توافق يستورد نقطة التشغيل الجديدة حتى لا تتعطل إعدادات النشر الحالية.

## خطة التقسيم

- `notifications/`: واجهة الإشعارات، OneSignal، الأرشيف والجدولة.
- `files/`: مركز الملفات وعمليات التخزين والحذف.
- `pwa/`: manifest وService Worker والأيقونات.
- `sheets/`: خدمة الجداول وواجهات API الخاصة بها.
- `shared/`: استجابات HTTP والتحقق والأدوات المشتركة.

مهم: هذه خطوة نقل آمنة لنقطة التشغيل فقط. لم نفصل الدوال الداخلية بعد؛ سيحدث ذلك تدريجياً مع اختبارات حتى لا تتغير سلوكيات لوحة الإشعارات.
